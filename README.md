# Neural Portfolio - AI Engineer & Full Stack Developer

A futuristic, high-performance portfolio website built with **React**, **Vite**, **Framer Motion**, and **GSAP**. This project features a cinematic "Neural" theme with interactive backgrounds, smooth transitions, and a weightless "Antigravity" animation system.

## 🚀 Features

- **Neural Ecosystem**: Interactive SVG constellation of skills and technologies.
- **Cinematic Visuals**: Dark-themed, glassmorphic UI with vibrant HSL-curated colors.
- **Fluid Motion**: Smooth scroll via Lenis and complex orchestrations with Framer Motion & GSAP.
- **Antigravity Engine**: Custom weightless floating system for UI elements.
- **Vercel Ready**: Optimized for edge deployment with SPA routing support.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4
- **Animations**: Framer Motion, GSAP, @tsparticles/react
- **Scrolling**: Lenis
- **Deployment**: Vercel

## 📦 Project Structure

- `/portfolionpm`: The primary React application.
- `/src/animations`: Raw source for the custom Antigravity animation system.
- `vercel.json`: Deployment configuration for Vercel.

## 🚦 Getting Started

1. **Install Dependencies**:
   ```bash
   cd portfolionpm
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## 🌍 Deployment

To deploy on Vercel:
1. Connect this GitHub repository to your Vercel account.
2. Set the **Root Directory** to `portfolionpm`.
3. Vercel will handle the rest!
