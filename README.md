# 🧠 Neural Portfolio - AI Engineer & Full Stack Developer

A futuristic, high-performance portfolio website built with **React**, **Vite**, **Framer Motion**, and **GSAP**. This project features a cinematic "Neural" theme with interactive backgrounds, smooth transitions, and a weightless "Antigravity" animation system.

## ✨ Key Features

- **Neural Network Visualization**: Dynamic, interactive particles and network graphs powered by `tsparticles`.
- **Intelligent Assistant**: A built-in AI assistant interface that provides context-aware information.
- **Skills Universe**: A 3D-feeling interactive skills cloud.
- **Antigravity Animation**: Custom physics-based animation system for a weightless UI experience.
- **Smooth Interaction**: Integrated `Lenis` smooth scrolling and custom `NeuralCursor`.
- **Responsive Design**: Fully optimized for all screen sizes with a premium dark-mode aesthetic.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/), [GSAP](https://greensock.com/gsap/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Visuals**: [tsParticles](https://particles.js.org/)

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Zeel555/Portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Deployment

The project is optimized for deployment on **Vercel**. Simply connect your GitHub repository to Vercel, and it will automatically detect the Vite configuration.
